# Prise en main

Trois étapes avant de travailler : **connecter** l'outil à Claude, **se connecter**, puis **choisir la classe et la matière**.

## 1. Connecter l'outil à Claude

L'outil se branche à Claude comme un « connecteur ». Votre administrateur vous fournit **une adresse** (une URL se terminant par `/mcp`).

1. Dans Claude, ouvrez les paramètres des connecteurs.
2. Ajoutez un connecteur et collez l'adresse fournie.
3. Validez.

!!! info "Vous n'avez pas d'adresse ou de compte ?"
    Les comptes sont créés par l'administrateur du projet (il n'y a pas encore d'auto-inscription). Demandez-lui votre accès et l'adresse du connecteur.

<!-- SCREENSHOT : écran d'ajout du connecteur dans Claude -->

## 2. Se connecter

À la première utilisation, Claude ouvre une page de connexion. Saisissez l'**e-mail** et le **mot de passe** fournis par votre administrateur. Vous ne le referez pas à chaque fois.

<!-- SCREENSHOT : page de connexion -->

## 3. Choisir la classe et la matière

Vous travaillez sur **une classe + une matière à la fois** (par exemple *CI / mathématiques*). Dites simplement à Claude ce sur quoi vous voulez travailler :

> « Travaillons sur les mathématiques de CI. »

Claude fixe le contexte. Pour savoir ce qui est disponible :

> « Quelles classes et matières sont disponibles ? »

!!! tip "Bon à savoir"
    Votre choix reste actif pendant votre session. Si vous changez de matière en cours de route, dites-le à Claude — il repart proprement sur le nouveau contexte.
